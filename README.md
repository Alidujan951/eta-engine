## 🛠️ Using the application

The main interface shows a workspace where you load your files. Click the Open button in the top left corner to select your data. The engine automatically reads the structure of your document. 

Once the data loads, the dashboard shows a summary of what the engine found. You can toggle specific settings in the sidebar to change how the engine handles your files. Click the Run button when settings look correct. The progress bar displays the status of the current job. 

When the task finishes, the software saves a new file in your documents folder. You can view the output immediately by clicking the link in the notification window.

## 📝 Common questions

### Does the software change my source files?
No. The engine creates a new file for the output. Your source data stays in its original state and position.

### Can I run multiple tasks at once?
The software handles one task at a time to keep your computer stable. Wait for the current progress bar to reach one hundred percent before you start the next job.

### Where do I find saved files?
The program saves results to your Documents folder under a new directory named eta-engine-exports. 

### How do I update the program?
The program checks for updates every time you open it. If a new version exists, a window appears asking if you want to install it. Click Yes to perform the update automatically.
